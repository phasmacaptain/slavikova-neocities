UPLOAD
------
Upload everything inside the slavikova-neocities folder to the root of your Neocities site. Keep the folder structure intact.

BLOG POSTS
----------
Duplicate posts/post-template.html, rename it using the date and a slug, write your post, then add a link to it inside blog.html.

WEBDECK PLAYER
--------------
The player is inside webdeck-player/. It uses the YouTube IFrame API and a locally bundled silver-style skin so there are no extra player font or image requests. It is based on the Webdeck Player project by Chris and keeps the MIT license in webdeck-player/LICENSE.txt.

To change playlists, open webdeck-player/script.js and edit the playlists object near the beginning. The values are YouTube playlist IDs, not full URLs. The default lists are public examples from the original Webdeck Player project.

PERFORMANCE
-----------
The site uses one local stylesheet and one small local site script. Most decorative images below the fold are lazy-loaded. The Webdeck iframe is lazy-loaded and the animated title pauses while the tab is hidden. Google Fonts uses preconnect and font-display swap through the official embed. No framework is included.

CUSTOMIZATION
-------------
- Add outfit photos to assets/outfits/
- Add cat photos by replacing the placeholders in cats.html
- Edit the text directly in each HTML file
- Edit colors and layout in style.css
- Change the animated tab-title text with the data-title-scroll attribute on each body tag
